# In-progress Ceremony hygiene rule centralised at the Nudge level

While a Ceremony performance is in progress (the user has opened the Ceremony but not yet completed or abandoned it), no Nudge of the underlying Ritual should surface — surfacing a Daily Planning Banner while the user is inside the Daily Planning wizard is incoherent. The question was where this rule lives in the model.

We considered two alternatives. The decentralised version: each Trigger's predicate includes "and no Ceremony performance of this Ritual is in progress." This preserves Trigger autonomy (Triggers own their full content predicate, with no Nudge-level rules) at the cost of every Trigger author having to remember the defensive non-content check. A new Trigger that forgets the check pesters the user during the Ritual. The split-Nudge version: model start-the-Ceremony and continue-the-Ceremony as two distinct Nudges, each with its own Trigger and satisfaction semantics. The "start" Nudge is satisfied the moment a performance begins; the "continue" Nudge fires only when a performance has been abandoned. This preserves Trigger autonomy *and* a clean separation, at significant implementation complexity and a vocabulary the user does not think in.

We chose a single centralised invariant: while any Ceremony performance of a Ritual is in progress, the Ritual's Nudge is hidden regardless of Trigger state. The rule lives on the Nudge, not on individual Triggers. It is a hygiene rule — single, universal, content-independent — distinct in kind from a Trigger's content predicate. Triggers remain autonomous about their *content* logic; the in-progress check is not their concern.

The trade-off is explicit: the Nudge model carries one named non-content rule that Triggers do not see. This is a small, named cost in exchange for foot-gun elimination (new Triggers cannot forget the rule) and avoiding the split-Nudge model's complexity. If a future requirement makes the "continue an abandoned performance" prompt meaningfully different from the "start a new performance" prompt — different copy, different surface, different timing — the split-Nudge model becomes preferable and this ADR will be superseded.
